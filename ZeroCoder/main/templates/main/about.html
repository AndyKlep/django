О проекте

Что такое CatDjango?

CatDjango — это учебный проект, созданный для практики веб-разработки на Python с использованием Django.

Главная цель проекта — научиться создавать многостраничные веб-сайты с единой структурой. Для этого используется базовый шаблон layout.html, от которого наследуются остальные страницы.

Меню и подвал вынесены в отдельные шаблоны nav.html и footer.html. Они подключаются в общий шаблон с помощью Django-тега {% templatetag openblock %} include {% templatetag closeblock %}. Поэтому не нужно копировать одинаковый HTML-код на каждую страницу вручную.

Интерфейс стилизован с Bootstrap: используются навигационная панель, карточки, кнопки, адаптивная сетка и готовые иконки. Страницы корректно отображаются на разных размерах экрана.

Следующий этап развития проекта — добавление моделей, базы данных, форм и пользовательского контента.
